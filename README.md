# Carom

Carom is a fast top-down paddle duel. Bend a glowing ball with paddle motion,
thread it past the center obstacles, and outscore your opponent.

## Run it

```bash
npm ci
npm run dev
```

Create a static production site in `dist/`:

```bash
npm run build
```

## Controls

- Left paddle: **W / S**
- Right paddle in Versus: **Up / Down**
- In Solo, either set of movement keys controls the left paddle.
- Menus: movement keys, **Enter** or **Space**
- Pause: **P** or **Escape**
- Mute: **M**

In Solo, the right paddle is an adaptive opponent. In Versus, bring a friend and
defend both ends of the arena.
